# FAQ Semantic Search Engine

Semantic search over the HuggingFace `wiki_qa` dataset using `sentence-transformers/all-MiniLM-L6-v2`.

Find answers even when your wording differs from the FAQ — powered by cosine similarity over sentence embeddings.
